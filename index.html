This demo needs the Vite dev server

index.html is the Vite entry point, not a standalone page — it loads /src/demo/main.tsx, which the browser cannot run by itself. That is why opening the file directly shows a blank screen. 

npm install
npm run dev

Then open the URL printed in the terminal (usually http://localhost:5173). To check the production build instead, run npm run build then npm run preview.
